# Campus Facility Reservation — Data Mining Midterm (Streamlit)

## Run
1. (Optional) create a virtual environment
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

The app opens at http://localhost:8501.

## Notes
- Uses a reproducible synthetic dataset (402 rows, seed 42) by default.
- You can change the seed, row count and decision-tree settings in the sidebar, or upload your own CSV.
- The Export tab downloads the cleaned CSV, data-quality summary, findings report, and the UML diagram (PNG + .drawio).
